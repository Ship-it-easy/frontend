# Маршрут — frontend

React/Vite-интерфейс с отдельными кабинетами по роли пользователя:

- `owner` — районы, владельцы и доступы диспетчеров;
- `dispatcher` — заявки, планирование, инженеры и справочники;
- `engineer` — сегодняшние, будущие и завершённые назначения.

При старте приложение проверяет сессию через `GET /api/auth/me`. Любой ответ
`401` завершает локальную сессию и возвращает пользователя на экран входа.

Экран «Планирование» показывает одну рабочую доску текущего семидневного плана:
вкладки дат, маршруты по инженерам, отдельную колонку неназначенных и перенесённых
заявок, отменённые снимки, поиск и фильтры. Карточка открывает объяснение решения
с проверками допустимости, факторами приоритета, параметрами маршрута и
техническим итогом. Во время перерасчёта опубликованный план остаётся доступным,
а состояние обновляется автоматически; при смене версии доска перечитывается
целиком. Для каждого выбранного дня над карточками отображается карта
OpenStreetMap: стартовые точки инженеров, заявки, их порядок и дорожные маршруты,
построенные через Valhalla. Если дорожный сервис недоступен, карта сохраняет точки
и показывает прямое соединение с предупреждением. Параметры расчёта, как и прежде, доступны только диспетчеру; владелец
может просматривать и запускать план выбранного района, инженер на этот экран
не допускается. Старый экран истории запусков удалён: раздел «Планирование»
всегда открывает новую семидневную доску.

Работа с доской: по умолчанию выбран текущий день района; вкладки переключают
семь дат без нового solver. Порядковый номер карточки — позиция в маршруте.
«Перенесена» означает, что заявка не назначена в выбранный день, но получила
назначение на указанную будущую дату. «Не назначена в горизонте» означает, что
назначения нет до конца рассчитанного горизонта. Во время нового расчёта экран
сохраняет предыдущий опубликованный план. Частичный результат остаётся валидным,
а причина каждой неназначенной заявки открывается из карточки.

Создание заявки автоматически ставит перепланирование в обработку; весь горизонт
публикуется атомарно без ручной публикации отдельных дней. Кабинет инженера
периодически получает актуальную версию плана и сообщает об изменении маршрута.

```bash
npm install
npm run dev
```

В development backend по умолчанию используется на порту `8000` того же
hostname, на котором открыт Vite. В production запросы по умолчанию same-origin;
для отдельного API-домена задайте `VITE_API_URL` во время сборки.
Vite проксирует `/valhalla` на `http://localhost:8002`; другой адрес можно задать
через `VITE_VALHALLA_URL`.
