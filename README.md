# Маршрут — frontend

React/Vite-интерфейс с отдельными кабинетами по роли пользователя:

- `owner` — проекты, владельцы и доступы диспетчеров;
- `dispatcher` — заявки, планирование, инженеры и справочники;
- `engineer` — сегодняшние, будущие и завершённые назначения.

При старте приложение проверяет сессию через `GET /api/auth/me`. Любой ответ
`401` завершает локальную сессию и возвращает пользователя на экран входа.

Экран диспетчера «Планирование» работает с управляемым многодневным каскадом:
показывает прогресс по дням, будущие черновики, остаток и подтверждённые причины,
поддерживает безопасную остановку и проверяет актуальность текущего дня перед
публикацией.

```bash
npm install
npm run dev
```

Backend должен быть доступен на `http://localhost:8000`. При необходимости URL меняется через `VITE_API_URL`.

Для дорожной геометрии на карте dev-сервер проксирует `/valhalla` на
`http://localhost:8002`.
